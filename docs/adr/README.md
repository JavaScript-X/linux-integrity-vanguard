# Architecture Decision Records

Architecture decision records (ADRs) capture choices that are costly or risky to
reverse. Copy the template below, assign the next four-digit number, and keep the
record in the repository even if a later ADR supersedes it.

## Template

```markdown
# ADR-NNNN: Decision title

- Status: proposed | accepted | superseded
- Date: YYYY-MM-DD
- Deciders: names or team

## Context

What forces and constraints require a decision?

## Decision

What was decided?

## Consequences

What becomes easier, harder, or newly required?

## Alternatives considered

What credible options were rejected, and why?
```
